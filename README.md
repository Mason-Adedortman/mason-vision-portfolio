## Run locally

This is a static HTML, CSS and JavaScript website. No dependency installation or compilation is required. With Python 3 installed, run from the repository root:

```sh
python -m http.server 4174
```

Open http://localhost:4174. A static development server such as your editor’s Live Server also works.

## Deploy to Vercel

1. Import this repository into Vercel.
2. Use the **Other** framework preset and the repository root as the root directory.
3. Leave install and build commands empty; use ` . ` (a single dot, without spaces) as the output directory.
4. Deploy. No environment variables are required.

The included `vercel.json` supplies the static settings. Fonts, posters and MP4 demos are committed with the site. Loom walkthroughs load on request and require an internet connection.

## Structure

- `index.html`: page structure, identity and project cards.
- `style.css`: responsive slate and mint visual design.
- `script.js`: navigation, modal interaction and video lifecycle.
- `project-data.js`: case-study copy, media and GitHub links.
- `assets/`: local fonts, licenses, favicon and project recordings.

## Media and accessibility

The hero uses a muted eight-second loop. Native project videos loop when opened, and stop when their modal closes. The hero pauses offscreen and while a modal is open. Reduced-motion and data-saving preferences are respected. Loom embeds load only after interaction.
